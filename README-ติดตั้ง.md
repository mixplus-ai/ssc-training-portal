# ระบบอบรมและใบประกาศนียบัตร (SSC Training Portal) · เวอร์ชัน 2

เว็บแอปสำหรับผู้เข้าอบรม: สมัครสมาชิก → จองรอบอบรมจากปฏิทิน → ชำระค่าอบรม (ถ้ามี) → สแกน QR เช็คอินหน้างาน → ดาวน์โหลดเอกสาร/ภาพบรรยากาศ → รับใบประกาศ (PDF มี QR ตรวจสอบ) → สะสมแต้มแลกของรางวัล
ทำงานบน **Google Apps Script** + **Google Sheet** เป็นฐานข้อมูล ไม่มีค่าโฮสติ้ง ใช้ได้ทั้ง PC / iPad / มือถือ

## 2. ติดตั้งครั้งแรก (ประมาณ 15 นาที)

1. เปิด Google Sheet → **ส่วนขยาย (Extensions) → Apps Script**
2. วางโค้ด: `Code.gs` (แทนของเดิม) และกด **+ → HTML** สร้าง `Index`, `Styles`, `App` แล้ววางโค้ดจากไฟล์ชื่อเดียวกัน
3. ⚙️ **Project Settings** → ติ๊ก “Show appsscript.json” → วางเนื้อหา `appsscript.json`
4. เลือกฟังก์ชัน **`setup`** → **Run** → อนุญาตสิทธิ์ (Advanced → Go to project → Allow)
   ระบบสร้างชีต หลักสูตร 3 หลักสูตร ค่าตั้งต้น และ **ตัวตั้งเวลาส่งอีเมลเตือนทุกวัน 08:00**
5. เทมเพลตใบประกาศ: อัปโหลด `templates/tpl-om-red.jpg`, `tpl-basic-green.jpg`, `tpl-commercial-blue.jpg` เข้า Google Drive → รันฟังก์ชัน **`installDefaultTemplates`**
6. **Deploy → New deployment → Web app** · Execute as: **Me** · Who has access: **Anyone** → คัดลอก Web app URL
7. เปิด URL → **สมัครสมาชิกคนแรก = ผู้ดูแลระบบอัตโนมัติ**

## 3. อัปเดตจากเวอร์ชัน 1
1. วางโค้ดใหม่ทับทั้ง 4 ไฟล์ (`Code.gs`, `Index`, `Styles`, `App`)
2. รัน **`setup`** อีกครั้ง (ข้อมูลเดิมไม่หาย ระบบเพิ่มชีตและคอลัมน์ใหม่ + ค่าตั้งค่าใหม่ + ตัวตั้งเวลา)
3. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ลิงก์เว็บเหมือนเดิม)
4. เข้าแอดมิน → รอบอบรม → แก้ไขรอบที่เปิดอยู่ ใส่ **ชั่วโมงอบรม** (ใช้คิดแต้ม) และกดบันทึก
5. รอบเดิมที่ยังไม่มีรหัสเช็คอิน: กดปุ่ม QR → “สร้างรหัสใหม่”
6. ตั้งค่า **PAY_INFO** (เลขบัญชีรับโอน) ที่ ตั้งค่าระบบ

## 4. ใช้งานประจำวัน

**ข้อมูลออก 50 ทวิ · ไม่คิด VAT · ใบเสนอราคา**
- ตั้งค่าระบบ → `WHT_PAYEE_INFO` ใส่ชื่อบริษัท สาขา ที่อยู่ เลขผู้เสียภาษี (บรรทัดละรายการ) แสดงให้ลูกค้าที่หัก ณ ที่จ่ายเห็นพร้อมปุ่ม “คัดลอก” ในหน้าชำระเงิน
- `PERSON_NO_VAT` = TRUE ให้บุคคลทั่วไปเลือก “ไม่ต้องการใบกำกับภาษี (ไม่คิด VAT)” ได้ · บุคคลทั่วไปไม่มีตัวเลือกหัก ณ ที่จ่ายอยู่แล้ว
- ปุ่ม “ขอใบเสนอราคา / ติดต่อเจ้าหน้าที่” ในหน้าชำระเงิน: ลูกค้ากรอกชื่อบริษัท สาขา ที่อยู่ รหัสไปรษณีย์ เลขผู้เสียภาษี ผู้ติดต่อ โทร อีเมล → บันทึกในชีต QuoteRequests + อีเมลแจ้งผู้ดูแล (หรืออีเมลใน `QUOTE_EMAIL`) → ดูได้ที่ แอดมิน → คำขอใบเสนอราคา (คัดลอกข้อมูล/ตอบอีเมล/ทำเครื่องหมายส่งแล้ว)

**ดาวน์โหลดสลิป / 50 ทวิ ตามรอบอบรม**
- แอดมิน → **การชำระเงิน & 50 ทวิ** → เลือกรอบอบรม (หรือกดไอคอนใบเสร็จในตารางรอบอบรม)
- แต่ละคนมีปุ่มดู/ดาวน์โหลด สลิป, 50 ทวิ และใบเสร็จ · ปุ่ม “ตรวจ” เพื่ออนุมัติ/ไม่ผ่าน
- ดาวน์โหลดรวมเป็น .zip ได้: 50 ทวิทั้งหมด, สลิปทั้งหมด หรือทุกไฟล์ (ตั้งชื่อไฟล์ตามชื่อผู้ออกใบเสร็จ) และ “สรุป CSV” สำหรับฝ่ายบัญชี
- ไฟล์ทั้งหมดเก็บใน Google Drive โฟลเดอร์ payments ของระบบ

**แก้ข้อความอีเมล**
- แอดมิน → **อีเมลแจ้งเตือน** มี 2 แบบ: อีเมลยืนยันการลงทะเบียน (ส่งทันที) และอีเมลแจ้งเตือนก่อนวันอบรม (ส่งทุกวัน 08:00 น. ล่วงหน้าตามจำนวนวันที่ตั้ง)
- พิมพ์ข้อความได้อิสระ กดตัวแปร เช่น `{ชื่อ}` `{วันที่}` `{สถานที่}` `{แผนที่}` เพื่อแทรกข้อมูลของแต่ละคน · `**ข้อความ**` = ตัวหนา · ลิงก์ https:// กดได้อัตโนมัติ
- ดูตัวอย่างได้ทันทีด้านขวา และกด “ส่งอีเมลทดสอบถึงฉัน” ก่อนบันทึกได้ · “คืนค่าเริ่มต้น” เพื่อกลับไปใช้ข้อความเดิม

**แบบฟอร์ม Sale ที่เชิญ / ช่องทางที่รู้จัก**
- เมื่อผู้อบรมเลือกรอบ ระบบจะแสดงกล่องให้ตอบ 2 ข้อ (บังคับตอบ) ก่อนกด “ยืนยันการลงทะเบียน”: ชื่อ Sale ที่เชิญ (มีตัวเลือก “อื่นๆ” ให้พิมพ์ชื่อเอง) และช่องทางที่รู้จักกิจกรรม (มี “อื่นๆ:” ให้ระบุ)
- เพิ่ม/ลบ/แก้ชื่อ Sale และช่องทาง: แอดมิน → ตั้งค่าระบบ → ช่อง `SALES_LIST` และ `SOURCE_LIST` (บรรทัดละ 1 รายการ)
- คำตอบเก็บในชีต Registrations คอลัมน์ `saleName` และ `source` และแสดงในรายชื่อผู้เข้าอบรมและไฟล์ส่งออก CSV

**จัดการรอบอบรม**
- **ทำซ้ำรอบ:** แอดมิน → รอบอบรม → ปุ่มคัดลอก (ไอคอนสองแผ่น) → ระบบคัดลอกหลักสูตร เวลา ชั่วโมง สถานที่ ค่าอบรม และเทมเพลตให้ เลือกแค่วันที่ใหม่แล้วกดบันทึก (ได้รหัสเช็คอินใหม่ ไม่คัดลอกรายชื่อผู้ลงทะเบียน)
- **ลบรอบ:** ปุ่มถังขยะ
  - ถ้ายังไม่มีใครลงทะเบียน ระบบจะลบแถวออกจากชีตเลย
  - ถ้าเป็นรอบที่ยังไม่จัดและมีผู้ลงทะเบียน ระบบจะยกเลิกการลงทะเบียนทั้งหมด (ไม่นับเป็นการผิดกติกาของผู้อบรม) ส่งอีเมลแจ้ง แล้วย้ายรอบไปที่แท็บ “ที่ลบแล้ว”
  - ถ้าเป็นรอบที่จัดไปแล้ว ระบบจะย้ายไปที่แท็บ “ที่ลบแล้ว” โดยประวัติการอบรมและใบประกาศของผู้อบรมยังอยู่ครบ
  - รอบในแท็บ “ที่ลบแล้ว” กดกู้คืนกลับเข้ารายการได้

**ก่อนวันอบรม**
- แอดมิน → รอบอบรม → ปุ่ม QR → **พิมพ์** หรือดาวน์โหลด PNG ไปตั้งที่จุดลงทะเบียน
- ไฟล์พรีเซนต์/โปรโมชั่น: ตั้ง “เปิดให้เห็น” = **หลังเช็คอิน และเมื่อถึงเวลาเริ่มอบรม**

**วันอบรม**
- ผู้อบรมสแกน QR ด้วยกล้องมือถือ → เข้าสู่ระบบ → เช็คอินอัตโนมัติ (เปิดก่อนเวลาเริ่ม 120 นาที) หรือกรอกรหัส 6 หลักที่เมนู “เช็คอินหน้างาน”
- เช็คอินแล้ว = สถานะ “เข้าร่วม” + ได้แต้มทันที · ดูจำนวนคนเช็คอินได้ที่หน้าภาพรวม

**หลังอบรม**
- อัปโหลดภาพบรรยากาศ: แอดมิน → ไฟล์ & รูปภาพงาน → ประเภท “รูปภาพงาน” → เลือกรอบ (เลือกได้หลายรูปพร้อมกัน)
- เลือกผู้เข้าร่วม → **ออกใบประกาศ** (หรือตั้ง `AUTO_ISSUE_ON_ATTEND = TRUE` ให้ออกทันทีเมื่อเช็คอิน)
- คนที่ไม่ได้เช็คอิน ระบบบันทึก “ไม่มา” อัตโนมัติวันถัดไป (นับ 1 ครั้งตามกติกา) ปิดได้ที่ `AUTO_NOSHOW = FALSE`

**การชำระเงิน** — ผู้อบรมโอนแล้วแนบสลิป → หน้าภาพรวมแจ้ง “สลิปรอตรวจสอบ” → เปิดรายชื่อ → ปุ่ม “ตรวจ” → ยืนยันรับชำระ (แนบใบเสร็จได้) หรือ “ไม่ผ่าน” → ระบบส่งอีเมลแจ้งผู้อบรม

**ของรางวัล** — แอดมิน → แต้ม & ของรางวัล: เพิ่มของรางวัลแลกตรง (กำหนดแต้ม/จำนวน) หรือรางวัลในกล่องสุ่ม (กำหนดน้ำหนักโอกาส) · เปลี่ยนสถานะเป็น “ส่งมอบแล้ว” เมื่อให้ของ · “ยกเลิก” = คืนแต้มอัตโนมัติ · ปิดหน้าแลกของรางวัลได้ที่ช่อง “หน้าแลกของรางวัล”

## 5. ค่าตั้งค่าสำคัญ (ชีต Settings / หน้า ตั้งค่าระบบ)
| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| MAX_ACTIVE_BOOKINGS | 5 | จองล่วงหน้าได้สูงสุดกี่รอบ |
| CHANGE_DAYS_BEFORE | 3 | เลื่อน/ยกเลิกได้ถึงกี่วันก่อนอบรม |
| STRIKE_LIMIT | 2 | เลื่อน/ยกเลิก/ไม่มา ได้กี่ครั้ง เกินนี้ระงับสิทธิ์ |
| CERT_VALID_MONTHS | 12 | อายุใบประกาศ (เดือน) |
| REMIND_DAYS | 5 | ส่งอีเมลเตือนก่อนกี่วัน |
| CHECKIN_OPEN_MINUTES | 120 | เปิดเช็คอินก่อนเวลาเริ่มกี่นาที |
| HERO_SPEED | 6 | วินาทีต่อสไลด์หน้าแรก |
| POINTS_PER_HOUR | 1 | แต้มต่อชั่วโมงอบรม |
| LUCKY_COST | 10 | แต้มต่อการสุ่ม 1 ครั้ง |
| VAT_RATE / WHT_RATE | 7 / 3 | อัตราภาษี (%) |
| REWARDS_ENABLED | TRUE | FALSE = ซ่อนหน้าแลกของรางวัลจากลูกค้า |

## 6. ข้อควรทราบ
- อีเมลส่งผ่าน Gmail ของบัญชีที่ Deploy: Gmail ทั่วไป ~100 ฉบับ/วัน, Google Workspace ~1,500 ฉบับ/วัน
- Google Calendar ไม่รับการตั้งแจ้งเตือนผ่านลิงก์ ผู้อบรมต้องตั้ง “1 วันก่อน” เอง · ไฟล์ .ics (iPhone/Outlook และไฟล์แนบในอีเมล) ตั้งแจ้งเตือน 1 วันให้อัตโนมัติ
- การชำระเงินเป็นแบบโอนแล้วแนบสลิป (ไม่ได้เชื่อมระบบตัดบัตร/QR พร้อมเพย์อัตโนมัติ)
- แต้มนับตามปีปฏิทิน (ม.ค.–ธ.ค.) ขึ้นปีใหม่เริ่มนับใหม่
- ไฟล์ใน Drive แชร์แบบ “ทุกคนที่มีลิงก์ดูได้” หน้าเว็บแสดงลิงก์เฉพาะผู้มีสิทธิ์ แต่ถ้าลิงก์หลุดก็เปิดได้
- อัปโหลดผ่านเว็บได้ไม่เกิน ~25MB ต่อไฟล์ วิดีโอให้ใช้ลิงก์ YouTube / Google Drive
- เหมาะกับผู้ใช้หลักร้อยถึงหลักพันคน
